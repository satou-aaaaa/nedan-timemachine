# 値段タイムマシン（nedan-timemachine）

昔の値段（はがき・新聞・映画館・ラーメンなど）を、消費者物価指数で今（2025年）のお金に直すと約いくらかを当てる1日5問の学習ゲーム。正解したら、今の本当の値段とくらべてどちらが高いかも選ぶ。物価指数の決まりの問題も出る。

遊ぶ: <https://satou-aaaaa.github.io/nedan-timemachine/>

- 数字は総務省統計局の消費者物価指数（2025年基準・東京都区部・持家の帰属家賃を除く総合・年平均）と、小売物価統計調査の値段だけです（出典の表記：総務省「消費者物価指数」「小売物価統計調査」）。
- 値段は東京都区部の平均です。品物の中身は年によって少しちがうので、今のお金に直した値段は目安です。品物の名前は一般名にしています。
- お金をかけたり、もうけを当てたりするゲームではありません。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。結果の「共有」を押したときだけ、その日の回の番号と各問の○×の並びが、選んだサービス（X・LINE など）に渡ります。
